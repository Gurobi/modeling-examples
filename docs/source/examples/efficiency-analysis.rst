Efficiency Analysis
===================

.. image:: thumbnails/efficiency-analysis.jpg
   :width: 600
   :align: center
   :alt: Efficiency Analysis

Data Envelopment Analysis (DEA) measures the productive efficiency of organizations by comparing the inputs and outputs of each unit against those of its peers. The problem is formulated as a linear program.
