3D Tic-Tac-Toe
==============

.. image:: thumbnails/3d-tic-tac-toe.jpg
   :width: 600
   :align: center
   :alt: 3D Tic-Tac-Toe

This model places X's and O's on a three-dimensional Tic-Tac-Toe board so as to minimize the number of completed lines and diagonals. It demonstrates how mixed-integer programming captures simple logical constraints.
