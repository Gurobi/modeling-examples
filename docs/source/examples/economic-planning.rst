Economic Planning
=================

.. image:: thumbnails/economic-planning.jpg
   :width: 600
   :align: center
   :alt: Economic Planning

This example models the interrelationships between the sectors of a country's economy using an input-output model. The goal is to determine possible growth patterns for the economy, and the model is formulated as a linear program.
