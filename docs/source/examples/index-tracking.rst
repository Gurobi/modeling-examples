Index Tracking
==============

.. image:: thumbnails/index-tracking.jpg
   :width: 600
   :align: center
   :alt: Index Tracking

Index tracking selects a subset of stocks whose portfolio closely replicates the return of a market index, while limiting the number of assets held. The problem is formulated as a mixed-integer quadratic program that minimizes the tracking error.
