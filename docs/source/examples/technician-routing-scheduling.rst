Technician Routing and Scheduling Problem
=========================================

.. image:: thumbnails/technician-routing-scheduling.jpg
   :width: 600
   :align: center
   :alt: Technician Routing and Scheduling Problem

This example assigns technicians to service jobs at customer sites, deciding each technician's route and the start time of each job while respecting time windows. The model is formulated as a mixed-integer program.
