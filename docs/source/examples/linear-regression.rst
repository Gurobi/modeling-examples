Best Subset Selection: L0-Regression
====================================

.. image:: thumbnails/linear-regression.jpg
   :width: 600
   :align: center
   :alt: Best Subset Selection: L0-Regression

Linear regression with feature selection chooses the subset of features that best explains the response, up to a specified number of features. The model is a mixed-integer quadratic program (MIQP), and it is benchmarked against ordinary least squares regression and the Lasso.
