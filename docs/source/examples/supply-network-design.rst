Supply Network Design
=====================

.. image:: thumbnails/supply-network-design.jpg
   :width: 600
   :align: center
   :alt: Supply Network Design

This example designs a supply network by deciding which plants and distribution centers to open and how product flows should be routed between them. The model is formulated as a mixed-integer program.
