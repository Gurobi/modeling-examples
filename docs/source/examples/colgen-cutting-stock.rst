Column Generation for the Cutting Stock Problem
===============================================

.. image:: thumbnails/colgen-cutting-stock.jpg
   :width: 600
   :align: center
   :alt: Column Generation for the Cutting Stock Problem

The cutting stock problem cuts stock material of fixed width, such as paper rolls, into smaller pieces that meet a set of orders while minimizing wasted material. This example solves the integer programming formulation with column generation, which iteratively adds promising cutting patterns to a restricted model.
