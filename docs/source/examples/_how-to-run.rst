**How to Run the Example**

- To run the example the first time, choose "Runtime" and then click "Run all".
- All the cells in the Jupyter Notebook will be executed.
- The example will install the ``gurobipy`` package, which includes a limited
  Gurobi license that allows you to solve small models.
- You can also modify and re-run individual cells.
- For subsequent runs, choose "Runtime" and click on "Restart and run all".

Check out the `Colab Getting Started Guide
<https://colab.research.google.com/notebooks/intro.ipynb>`_ for full details on
how to use Colab Notebooks as well as create your own.
