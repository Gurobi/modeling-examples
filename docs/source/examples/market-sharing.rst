Market Sharing
==============

.. image:: thumbnails/market-sharing.jpg
   :width: 600
   :align: center
   :alt: Market Sharing

This example is a goal programming problem in which retailers are allocated to two divisions of a company. The allocation balances several market sharing goals, and the problem is formulated as a mixed-integer linear program.
