Curve Fitting
=============

.. image:: thumbnails/curve-fitting.jpg
   :width: 600
   :align: center
   :alt: Curve Fitting

This example fits a function to a set of observations of two quantities, x and y. Given the collected values, it identifies a function of x that explains the values of y. The fitting problem is formulated as a linear program.
