Constraint Optimization
=======================

.. image:: thumbnails/constraint-optimization.jpg
   :width: 600
   :align: center
   :alt: Constraint Optimization

Given a constraint over binary decision variables, this example finds another constraint on the same variables that is logically equivalent to the original but has the smallest possible absolute value of the right-hand side. The problem is a binary optimization problem.
