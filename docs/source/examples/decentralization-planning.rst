Decentralization Planning
=========================

.. image:: thumbnails/decentralization-planning.jpg
   :width: 600
   :align: center
   :alt: Decentralization Planning

Given a set of company departments and the candidate cities where they can be located, this example determines the best location for each department in order to maximize gross margins. The problem is formulated as a quadratic assignment problem.
