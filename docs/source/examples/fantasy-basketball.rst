Fantasy Basketball
==================

.. image:: thumbnails/fantasy-basketball.jpg
   :width: 600
   :align: center
   :alt: Fantasy Basketball

In fantasy sports, participants select players from a slate of real games to fill out a virtual lineup. This example formulates the lineup selection as an optimization problem that maximizes expected fantasy points under the contest's rules, using a mixed-integer program.
