Facility Location
=================

.. image:: thumbnails/facility-location.jpg
   :width: 600

   :alt: Facility Location

This example decides where to build warehouses so that they can supply a given set of supermarkets at minimum cost. It constructs a mixed-integer programming model of this facility location problem.
