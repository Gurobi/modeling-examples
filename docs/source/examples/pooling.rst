Standard Pooling Problem
========================

.. image:: thumbnails/pooling.jpg
   :width: 600
   :align: center
   :alt: Standard Pooling Problem

The pooling problem arises in petrochemical refining, wastewater treatment, and mining. It generalizes the minimum-cost flow and blending problems, and the resulting model is a nonconvex quadratically constrained program (QCP).
