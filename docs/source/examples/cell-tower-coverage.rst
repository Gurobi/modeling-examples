Cell Tower Coverage
===================

.. image:: thumbnails/cell-tower-coverage.jpg
   :width: 600
   :align: center
   :alt: Cell Tower Coverage

This example solves a covering problem: how to build a network of cell towers that provides signal coverage to the largest number of people possible. The problem is formulated as a mixed-integer program.
