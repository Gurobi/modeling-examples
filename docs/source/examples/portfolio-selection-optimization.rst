Portfolio Selection Optimization
================================

.. image:: thumbnails/portfolio-selection-optimization.jpg
   :width: 600
   :align: center
   :alt: Portfolio Selection Optimization

This example implements the classic Markowitz portfolio selection model, which allocates investments to minimize risk. It uses the Gurobi Python matrix interface and solves the model parametrically to trace the efficient frontier.
